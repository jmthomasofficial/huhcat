FAQ

Questions? Answered.

Is the image actually stored on-chain? +

Yes. The image is base64-encoded and embedded directly inside the token metadata via a V1 transaction — no IPFS, no CDN, no off-chain dependency.

What are V1 transactions? +

V1 transactions are a new Solana transaction format that allows richer, larger inscribed data to live natively inside a transaction — enabling things like fully on-chain images for the first time.

Is the contract safe? +

Mint and freeze authorities are revoked, and liquidity is locked/burned. Always DYOR and verify on-chain yourself — links to Explorer and Solscan are above.

Why does this matter? +

Because it's a documented Solana first — the same image that launched V1 inscriptions on testnet is now permanently sealed into a mainnet token. That's a piece of chain history you can hold.
